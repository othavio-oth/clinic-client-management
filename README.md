# Rapport — Next.js conversion

Projeto Next.js que serve como envelope para os arquivos HTML exportados.

Como usar:

1. Instale dependências:

```bash
npm install
```

2. Rode em modo de desenvolvimento:

```bash
npm run dev
```

3. Abra no navegador: http://localhost:3000 — links para `index.html` e `mpn9wx5e-index.html` estão na página inicial.

Notas:

- Os HTMLs originais foram copiados para a pasta `public/` para preservação fiel do design.
- Se quiser migrar o conteúdo para componentes React, posso ajudar na conversão por tela.
